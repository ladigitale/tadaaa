Tadaaa — offline-first shared todo lists

Tadaaa keeps your task lists in your browser (IndexedDB) and works offline. Sign in when you want cloud sync across devices, shared lists with invite links, webhooks and embeds — or keep exploring without an account. It is a free demo and open source (MIT).

  • Local first: tasks and tags stored on this device, usable without a server
  • Optional cloud sync with near-realtime updates, dataset sharing (reader / writer roles)
  • MCP server for AI agents at https://api.tadaaa.space/mcp (OAuth or personal access token)
  • Calendar and due dates, simple recurrence, link detectors, installable PWA, English / French UI
