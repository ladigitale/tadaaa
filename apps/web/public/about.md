# About Tadaaa

Tadaaa is an open-source, offline-first todo list application. Tasks and tags are stored in the browser and work without a server; an optional cloud account adds sync between devices, shared lists, webhooks, embeds and an MCP server so AI assistants (Claude, Cursor…) can work with your tasks.

- Front end: Lit and the Concorde web components framework (Vite, IndexedDB)
- API: Symfony 8, API Platform, FrankenPHP, PostgreSQL
